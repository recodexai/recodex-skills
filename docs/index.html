What Is It

不是 RSS，不是 API
是 Agent 原生的情报源

传统的信息订阅方式是给人类设计的。RecodeX Skill 是为 AI Agent 设计的——结构化、可检索、可直接用于决策。

📡

传统 RSS

为人类阅读器设计
  • ✗ 返回原始 XML，需解析
  • ✗ 无结构化融资元数据
  • ✗ 无法按赛道/金额筛选
  • ✗ Agent 无法直接理解
⚙️

REST API

为开发者集成设计
  • ✓ 返回 JSON
  • ✗ 需编写集成代码
  • ✗ 需了解端点结构
  • ✗ Agent 无法自动发现
⚡

RecodeX Skill

为 AI Agent 原生设计
  • ✓ 结构化 JSON 输出
  • ✓ 内置融资元数据
  • ✓ 一条命令按赛道筛选
  • ✓ Agent 自动识别和调用
How It Works

三步接入，零代码开发

安装 Skill 后，你的 AI Agent 就能用自然语言查询全球创投数据。无需 API Key，无需编码。

1

安装 Plugin

将 recodex 目录放入 Agent 的 plugins 文件夹。零依赖，纯 Python stdlib。

2

自然语言提问

"帮我看看今天有哪些 AI 赛道的融资"
"查一下 a16z 最近投了哪些公司"
Agent 自动识别并调用。

3

获取结构化结果

返回公司名、融资金额、轮次、投资方、官网等结构化数据，直接辅助投资决策。

Commands

六大命令，覆盖所有场景

从最新动态到精准筛选，一行命令获取你需要的创投数据。

🕐
latest
获取最新的原创报道或快讯，按发布时间倒序排列。
recodex_cli.py latest --type startup --limit 10 --output latest.json
🔍
search
按关键词全文搜索——公司名、投资方、技术领域。
recodex_cli.py search --query "a16z" --type startup --limit 10
📂
category
按赛道分类浏览，覆盖 AI、金融科技、医疗等 17 个赛道。
recodex_cli.py category --name "AI人工智能" --limit 10
🏢
company
精确查询特定公司的融资详情和完整报道。
recodex_cli.py company --name "Ocean" --output ocean.json
🔥
trending
获取今日或本周的全部内容，掌握热点动态。
recodex_cli.py trending --period today --output today.json
💰
funding
按融资轮次或金额筛选，快速定位目标交易。
recodex_cli.py funding --round "Seed" --limit 20 --output seeds.json

Installation

60 秒完成安装

零依赖，纯 Python stdlib，无需 pip install。

1

克隆 Plugin 到本地

将 RecodeX Plugin 目录复制到你的 Agent 插件目录。

git clone https://github.com/recodex/recodex-skill.git ~/.gemini/config/plugins/recodex
2

重启 Agent 会话

启动新的 AI Agent 会话，Skill 会自动加载到可用技能列表中。

# Skill 自动出现在 Available Skills 列表中
# 无需额外配置，即插即用
3

用自然语言提问

直接向你的 Agent 提问创投相关问题。

"帮我看看今天有哪些 AI 赛道的新融资"
"查一下 Lightspeed 最近投了哪些公司"
"Ocean 这家公司融了多少钱？"
